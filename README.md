# To-do-List-App

## Program Overview
The CLI To-Do List App is a simple command-line application built with Python that helps users organize and manage their daily tasks. It allows users to add new tasks, view existing tasks, mark tasks as completed, delete tasks, and view basic task statistics.

---
## Features
- Add new tasks with an optional priority level (Low, Normal, or High)
- View all saved tasks
- Mark tasks as completed
- Delete unwanted tasks
- View task statistics
- Compare task names with their completion status
- Handles invalid user input 
- Runs continuously until the user chooses to exit

---
## What the Program Does
When the program starts, it displays a menu with several options.

Users can:
1. Add a new task.
2. View all tasks currently stored.
3. Mark a selected task as completed.
4. Delete a selected task.
5. Display statistics such as:
      - Total number of tasks
      - Completed tasks
      - Remaining tasks
      - Lowest task number
      - Highest task number
6. Display a summary of each task and its current status.
7. Exit the application.

The application continues running inside a loop until the user selects the Exit option.

---
## How to Run

1. Save the program.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run the script.
